# CHANGELOG

This file lists all the updates made to our Amazing Business Computing (ABC) project.

---

## Version v1.1.0 – September 12, 2026
- Basic menu setup and continuous Yes/No loop for adding items.
- Added support for item names, prices, and budget input.

---

## Version v1.0.0 – September 28, 2026

- First release of the ABC (Amazing Business Computing) program.
- Added main menu options:
    - *A.* Input Data (add items and enter budget)
    - *B.* Check Statistics (view past purchases)
    - *C.* Compute Profit or Loss
    - *D.* Exit
- Program automatically calculates total revenue from entered items.
- Displays whether the business made a profit or a loss based on the budget.
