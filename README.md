# Project Title: 
ABC (Amazing Business Computing)

## Project Description: 
This program is designed to help small businesses figure out if they will be making a profit or a loss when buying items for their stores. 
It allows users to store items, manage their budget, track past purchases, and compute whether their transactions result in a profit or a loss.

## How to Run the Program:
1. Make sure you have Python installed on your computer.
2. Download or copy the project code into a file named `business_tracker.py`.
3. Open your terminal or command prompt.
4. Run the program using Python.
5. Follow the on-screen menu instructions to enter choices, item prices, and budgets.

## Input Needed:
Menu Selection: Capital or lowercase letters (A–G) to navigate the options.
Item Price:Numeric values (decimals allowed) representing the cost of items.
Budget: Numeric values representing the available funds.
